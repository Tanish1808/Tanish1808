### 🏛️ System Architecture Flowchart

```mermaid
flowchart TD
    subgraph ClientLayer ["Client & Ingestion"]
        U[User / Citizen] -->|HTTP / REST Request| GW[API Gateway & Route Auth]
        GW -->|JWT Role Validation| AUTH{Authorized?}
    end

    subgraph BackendLayer ["Backend Services"]
        AUTH -->|Valid Role| APP[Django REST / Flask Business Layer]
        AUTH -->|Inference Path| ML[FastAPI PyTorch ML Service]
    end

    subgraph DataLayer ["Data & Storage Layer"]
        APP --> DB[(PostgreSQL / MySQL Relational Data)]
        ML --> GEO[(MongoDB 2dsphere Spatial Index)]
        GEO --> DEDUP{Duplicate Check}
        DEDUP -->|Unique| DB
        DEDUP -->|Duplicate| MERGE[Cluster / Append to Ticket]
    end

    subgraph Presentation ["Output & Dashboards"]
        DB --> DASH[Admin Analytics & Public Dashboards]
        MERGE --> DASH
    end
```
