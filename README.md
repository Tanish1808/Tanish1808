#### 🎫 FEATURED PROJECT &bull; Ticket Tally — Smart IT Ticket Management System

<p>
  <img src="https://img.shields.io/badge/Status-🟢_LIVE_ON_RENDER-46E3B7?style=flat-square&logo=render&logoColor=black" alt="Render Live" />
  <img src="https://img.shields.io/badge/Stack-FLASK_·_POSTGRESQL_·_JS_·_JWT-080C14?style=flat-square" alt="Stack" />
</p>

<p>
  <strong>The Problem:</strong> Internal IT issues can become difficult to track, prioritize, and resolve systematically without explicit role scopes and priority queues.
</p>
<p>
  <strong>The System:</strong> A role-based support platform covering the complete ticket lifecycle—from submission to algorithmic priority assignment, resolution, and audit reporting.
</p>

```
Employee Request ──► JWT Auth Gate ──► Priority Assignment ──► IT Staff Desk ──► State Transitions & SLAs ──► PostgreSQL
```

* **Core Engineering:**
  * Three-tier role-based access control (`Employee`, `IT Staff`, `Admin`) enforced at the route level via stateless JWT claims.
  * Priority Queue-based dispatch logic to prevent urgent system-down incidents from waiting behind trivial tickets.
  * State-machine bound SLA tracking tied directly to status changes (`CREATED` &rarr; `IN_PROGRESS` &rarr; `RESOLVED`).
  * Automated email notifications and dynamic PDF ticket generation upon resolution.
  * Containerized and deployed on **Render Cloud (Free Tier)**.

#### 🌍 Civic Lens — AI-Powered Civic Reporting Platform

<p>
  <img src="https://img.shields.io/badge/Stack-REACT_·_DJANGO_·_DRF_·_FASTAPI_·_PYTORCH_·_MONGODB-080C14?style=flat-square" alt="Civic Lens Stack" />
</p>

<p>
  <strong>The Concept:</strong> A citizen reporting platform for infrastructure issues using geotagged photos and a public transparency dashboard, engineered with a two-stage duplicate detection pipeline.
</p>

```
Citizen Report ──► Image / GPS ──► PyTorch Classification ──► MongoDB 2dsphere ──► Duplicate Detection ──► Public Transparency
```

* **Core Engineering:**
  * **Two-Stage Deduplication:** Uses MongoDB `2dsphere` spatial indexing for fast proximity radius matching ($O(\log N)$) before running expensive perceptual hashing (pHash) and PyTorch CNN feature embedding similarity checks on localized candidates ($O(K)$).
  * **Service Separation:** Decoupled FastAPI async inference routines from Django REST Framework business logic to isolate compute latency from standard requests.
  * **Confidence Routing:** Low-confidence predictions route to a manual verification queue, preventing model uncertainty from corrupting public telemetry.
