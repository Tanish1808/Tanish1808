#### 🌍 Civic Lens

### `AI-Powered Civic Reporting Platform`

<p>
  <img src="https://img.shields.io/badge/Stack-REACT_·_DJANGO_·_DRF_·_FASTAPI_·_PYTORCH_·_MONGODB-080C14?style=flat-square" alt="Civic Lens Stack" />
</p>

<p>
  A citizen incident reporting platform engineered with an asynchronous two-stage deduplication pipeline that prevents repeated submissions of the same localized issue.
</p>

```
PHOTO + LOCATION ──► AI CLASSIFICATION ──► SEVERITY ──► DUPLICATE DETECTION ──► PUBLIC TRANSPARENCY
```

* **Technical Mechanisms:**
  * **Two-Stage Deduplication:** MongoDB `2dsphere` spatial indexing filters nearby candidates ($O(\log N)$) before running perceptual hashing (pHash) and PyTorch CNN feature embedding similarity ($O(K)$).
  * **Service Separation:** Decoupled FastAPI async inference routines from Django REST Framework business logic to isolate compute latency.
  * **Confidence Routing:** Softmax confidence thresholding routes uncertain predictions into manual verification queues.
